# Dadminton – Badminton Notes

Tactical note taking for junior singles badminton. One self-contained file, runs in any browser: open `index.html`.

- Draw the shuttle's path on a top view or side view (height) of the court. Each time the line turns back towards the net, the player on that side hit it. Where it ends decides the point (win, out, wide, into the net).
- Tap a half for a fault by that player. Quick +/- score corrections.
- Several games per match, point target, win by 2, cap and time limit per game.
- Compare several matches side by side with stats and notes.
- Export/import JSON, export CSV. Data is saved in the browser (localStorage).
- Full screen mode with an exit button.
